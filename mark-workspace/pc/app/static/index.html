Каде да оди селекцијата?

Без plugin, ѕвезди или знаменца. 🟢 Green одбрани · 🔴 Red матни · 🟡 Yellow за проверка · 🟣 Purple дупликати. Нови фотографии: Lightroom Import → Add. Веќе во каталог: Metadata → Read Metadata from File (прво backup од каталогот). Кога е вклучен Lightroom режим, се менуваат метаподатоци во оригиналните JPG и RAW sidecar; се чуваат backup копии од постојните метаподатоци.

Не е избрана папка

Подготвено.

JPG / PNG / TIFF / WebP / NEF / CR2 / CR3 / ARW / DNG и други RAW • зачувува структура на подпапки • копира во НАЈДОБРИ КАНДИДАТИ, МАТНИ, ТЕМНИ, СЛИЧНИ/ДУПЛИКАТИ, ПРЕСВЕТЛИ.
