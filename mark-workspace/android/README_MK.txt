TD Booking 6.20 · Календар, страници и преглед по свадба

Инсталирај TD_Booking_v6_20_CALENDAR_PAGES.apk како надградба врз постојната TD Booking.
Пакет: mk.td.booking6. VersionCode: 80. Потписот е ист со проверената v6.19.

ОРГАНИЗАЦИЈА
• Прва страница: Календар. Кликни ден за да ги видиш сите свадби за тој датум.
• Календар → свадба: Преглед / Пари / Екипа / Договор.
• Пари во свадба: Уплати / Експрес / Услуги / Трошоци.
• Долно мени: Календар / Свадби / Финансии / Екипа / Поставки.
• Екипа: Локална екипа и посебно Покани и Cloud.
• Поставки: Синхронизација / Резервни копии / Мои пакети / Изглед и лого / TD Cloud / Извештаи.
• Синхронизацијата е преместена во Поставки → Синхронизација.
• Извештаите и Бизнис прегледот се достапни и од страничното мени.
• „На овој датум“ започнува нова резервација со избраниот датум.
• Може да се пребарува свадба по младенци, телефон, место или датум и да се филтрира по статус.
• Враќањето назад работи меѓу страниците; незачувани измени бараат потврда пред напуштање.

ПОДАТОЦИ И ПРОВЕРКИ
Резервациите и финансиските записи се користат во постојниот формат. Нема миграција,
дуплирање или иницијално презапишување на лични записи. Постојните потписи и заклучени
договори се зачувани. Експрес е одделен од клиентските уплати како и претходно.
Изборот на лого и персонализираната кратенка од v6.19 остануваат функционални преку
Поставки → Изглед и лого. Native Android кодот, ресурсите и постојните business scripts
се byte-for-byte исти со v6.19. Додадени се само два UI фајла и променета е верзијата.

Поминаа 93 автоматски проверки: 24 интеграциски проверки на интерфејсот, 50 финансиски
проверки и 19 за брендирањето. Интеграциските проверки се во Chromium со симулирани
native интерфејси, вклучувајќи локално file:// вчитување, податоци, уплати, исплати,
потпишување, копии, историја, повеќе свадби на ист датум и ширини 320–800 px.
Не е извршен тест на физички Android уред. Native синхронизација со вистински PC
не е тестирана во оваа сесија; native кодот и протоколот се непроменети.

ИЗРАБОТКА НА APK
Ова е кодот за надградбата врз проверената бинарна основа TD Booking 6.19.
Потребни се Python 3.10+, Python cryptography, Java 17+ и оригиналниот приватен
PKCS12 signing keystore. Приватниот клуч и неговата лозинка не се вклучени.
Постави ја лозинката приватно во TD_BOOKING_KEY_PASSWORD, па изврши:
python3 build_v620.py --keystore /private/path/to/td-booking6.jks
Резултатот се потврдува и со официјалниот apksigner вклучен во tools/.

ТЕСТОВИ
npm install
npx playwright install chromium
npm test
По желба постави TD_TEST_BROWSER на патеката на постоечки Chromium executable.
Тестовите користат само измислени примери, пресретнат мрежен сообраќај и симулирани
native интерфејси; не треба пристап до лични сметки или телефон.
