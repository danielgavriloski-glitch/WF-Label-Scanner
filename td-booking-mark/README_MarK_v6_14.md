# TD Booking v6.14 MarK - изворен проект (Android Studio)

Ова е ЦЕЛОСНИОТ изворен проект за компајлирање, со постојните функции и MarK синхронизација.
Гарантирани IDs: Android `mk.td.booking6`, versionCode 74. Има native избор на лого од Галерија.

1. Отвори го овој директориум во Android Studio, JDK 17, Android SDK 35.
2. Generate Signed APK (Release) со приватниот оригинален TD Booking keystore кој е во постојната приватна v6.10 архивска копија, НЕ во овој ZIP.
3. Инсталирај само ако потписот одговара на веќе инсталираната апликација.
4. MarK Desktop мора да го има активен сопствениот HTTPS LAN server на порта 8766 со истиот fingerprint за спарување.
5. На телефон во MarK: адреса, SHA256 отпечаток, спореди го кодот и потврди од PC, потоа синхронизирај.

ВАЖНО: CI / Android Studio APK не е компајлирана или тестирана на вистински телефон во оваа сесија.
Автоматскиот дел од v6.14 на PC ги прима само продукциските полиња за свадбите; не е дуплекс уредување на сите финансиски полиња.

Посебната потпишана v6.13 PREVIEW APK служи за MarK лого/тема и рачен JSON извоз до PC; нема автоматски LAN native bridge. Не ја нарекувај full sync.
